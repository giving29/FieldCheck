# FieldCheck × LOVB — Tactical Sprint Map
**Concrete things that get done. Each sprint ships value AND earns the next level of access.**
_Sprints are ~1–3 weeks. Value-first. We move at Kevin's rhythm._

---

## SPRINT 0 — THE HEAD-TO-HEAD PROOF  *(the audition)*
**Ship:** LOVB top 15–20 vs MLV top 15–20, position by position + full-roster ranking, LOVB superior.
**Tasks:**
- [ ] Get LOVB roster from Kevin (names, positions) — THE unlock
- [ ] Compile MLV rosters (public sources)
- [ ] Grade every athlete both sides through the engine
- [ ] Build position view (OH vs OH, S vs S, L vs L, MB, OPP)
- [ ] Build full-roster ranked view, both sides
- [ ] Write the takeaway lines ("LOVB is the top league — the independent number proves it")
- [ ] Package: clean shareable page + deck
**Earns:** league trust → the roster relationship → Sprint 1.
**Engine note:** relative ordering is exactly what a comparison needs — reliable today. No recalibration blocker.

## SPRINT 1 — THE DIFFERENTIATION ASSET  *(league-ready)*
**Ship:** every LOVB athlete graded, packaged for sponsors / recruiting / fan-facing.
**Tasks:**
- [ ] Full LOVB roster graded + profiles
- [ ] Sponsor-deck version (the "we're the top league" asset)
- [ ] Fan-facing version (the gap as a story)
- [ ] A "living" page LOVB can point anyone to
**Earns:** league adoption of the asset → Sprint 2 club conversations.

## SPRINT 2 — CLUB PILOT  *(one club, prove the ticket-sales angle)*
**Ship:** one LOVB club, fully graded, with a fan-facing "how your club stacks up" angle.
**Tasks:**
- [ ] Kevin opens one club (the friendliest / most engaged)
- [ ] Club roster graded + rivalry/matchup angles
- [ ] A fan-facing artifact the club can post/use
- [ ] Measure engagement (the ticket-sales thesis, tested small)
**Earns:** proof the club model works → roll to all clubs.

## SPRINT 3 — CLUB ROLLOUT  *(all clubs)*
**Ship:** every club graded, each with its own fan-facing angle + matchup storylines.
**Earns:** FieldCheck becomes league-wide fixture → the platform conversation.

## SPRINT 4 — THE LIVING GRAPH  *(infrastructure)*
**Ship:** the talent graph updates over time — rising players, development tracking, a real dashboard
for the league office + clubs.
**Earns:** FieldCheck is now infrastructure LOVB runs on. Sticky. Defensible.

## SPRINT 5 — PIPELINE  *(recruiting + development down the stack)*
**Ship:** college/juniors/international grading — who's coming up, who to recruit.
**Earns:** recruiting-intelligence line + deeper moat.
